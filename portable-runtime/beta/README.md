# Linux beta helpers

Start with the repository-level [`BETA_TESTING.md`](../../BETA_TESTING.md).

These tools build and stage Test-OpenCPN without system installation, launch
it with isolated HOME/XDG/config/plugin paths, run iGRIB conformance and create
a privacy-limited diagnostic archive. They are beta tooling and do not make
the portable runtime safe for navigation-critical use.
